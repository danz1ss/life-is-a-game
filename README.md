# Life is a Game

Текущая версия: **1.0.0**.

Локальная RPG-система саморазвития для Windows. Квесты приносят XP персонажу и связанным навыкам, дерево показывает общую карту развития, а заработанные монеты можно тратить на личные награды.

## Что уже работает

- планирование во вкладке «Квесты»: сводка «Сегодня», отдельный список «Завтра» и «Предстоящие» с сортировкой по датам, затем без даты;
- кнопка «Завтра» на главной, отдельные главный квест и порядок задач для каждого дня; при закрытии дня незавершённые одноразовые квесты остаются на исходной дате для решения;
- за новые уровни персонажа открываются образы, этапы питомца, памятные значки и личные поощрения; монеты за повышение уровня не начисляются;
- графитовые панели в «Текстуре» и «Минимализме», тёмно-синие navy-панели и космический фон с туманностями в «Ночном небе», голубые акценты и карточка персонажа «Сияние»;
- переключение фона через «Оформление» в боковом меню: «Текстура», «Ночное небо» и «Минимализм»; выбор сохраняется в профиле и резервной копии, все фоны работают без интернета;
- одинаковые круглые кнопки выполнения и невыполнения, контрастные описания и время задач;
- зелёная, фиолетовая и янтарная гаммы направлений с отдельным оттенком каждого навыка в задачах, дереве и прогрессе; существующие стандартные цвета обновляются с сохранением всех данных;
- утверждённый экран «Сегодня»: отдельные рамки дневного и недельного фокуса, доска задач, крупный герой и все конечные навыки под ним;
- 3–5 главных задач недели, отдельные планы Пн–Вс, чекбоксы, правка/удаление/отмена, воскресное ревью, план следующей недели и история; сохранение в SQLite и резервной копии схемы 6, безопасная миграция старых схем 1–5;
- перестановка задач только за ⋮⋮ с линией вставки, сохранением порядка и Alt+↑/↓;
- расписание с переносом задач на часовую шкалу, шагом 15 минут и быстрым редактором времени;
- одноразовые и повторяющиеся квесты;
- удаление квестов через меню «⋯» или редактор, с отменой в уведомлении (до его закрытия или выхода из приложения); заработанные XP, монеты и история сохраняются;
- три уровня сложности, XP, уровни и монеты;
- единое интерактивное дерево с отдельными ветками;
- 40 иконок навыков с поиском и категориями, создание поднавыка прямо из дерева;
- крупный герой и увеличенные узлы, переход к герою и обзор всей карты;
- стартовое дерево для новых профилей: «Здоровье» → «Спорт», «Сон»; «Развитие» → «Чтение», «Английский»; «Карьера» → «Программирование»;
- вкладка «Прогресс» с уровнем, XP, балансом монет, героем, питомцем и ближайшими открытиями;
- смена образа в модальном окне и путь открытий до 100 уровня в окне развития;
- магазин личных наград, подтверждение покупки и раздел «Мои награды» для использования купленного; награду можно настроить для немедленного использования;
- иконка с дракончиком и кристальным мечом; мальчик и девочка проходят шесть этапов взросления до 100-го уровня, с отдельными образами, одеждой и снаряжением;
- питомец стоит рядом с героем в общей сцене, имеет имя и выбор вида; он меняется на уровнях 5, 15, 30, 50 и 100, а дракончик и кристальный меч открываются на 100-м уровне;
- выбор причёски, капюшона, одежды, доспехов, оружия и цветового акцента в окне «Изменить образ»;
- импорт и экспорт резервной копии;
- отдельный планировщик без дубляжа сегодняшнего списка;
- разбор пропущенных одноразовых квестов без штрафов и автопереноса: после закрытия дня они сразу появляются в «Требуют решения»; «Уже выполнено» засчитывает плановый день, а фактическую дату можно выбрать отдельно;
- архив завершённых и отменённых задач с группировкой по дням, начиная с недавних;
- одна активная долгосрочная цель с полем «Зачем» для каждого навыка;
- XP и монеты за достижение главной цели.

При первом запуске версии 0.2.0 данные MVP автоматически мигрируют: существующие квесты, навыки, XP, монеты и история сохраняются.

## Приватность

В готовом приложении интерфейс загружается только из локальных файлов. Внешние HTTP(S) и WebSocket-запросы блокируются процессом Electron. Аккаунтов, телеметрии, аналитики и облачной синхронизации нет.

Данные хранятся в SQLite:

```text
%APPDATA%\life-is-a-game\life-is-a-game.sqlite
```

Резервную копию можно сохранить через пункт «Данные приложения» в боковом меню.

## Запуск

Готовый установщик находится в папке `release`:

```text
Life is a Game Setup 1.0.0.exe
```

Для разработки:

```powershell
npm install
npm run dev
```

Для проверки локальной production-сборки:

```powershell
npm run build
npm run desktop
```

Для создания нового установщика:

```powershell
npm run dist
```

## Проверки кода

```powershell
npm test
npm run typecheck
npm run test:electron
```

`test:electron` собирает приложение и проверяет переходы между страницами, сохранение при быстром закрытии, отказ загрузки повреждённых данных, отклонение некорректной резервной копии и повторное сохранение после ошибки SQLite. Проверки используют отдельные временные профили; личные данные приложения не затрагиваются.

Также проверяются создание завтрашнего плана, независимость главного квеста и порядка задач, сохранение времени и переход подготовленного плана на сегодня после смены даты. Для наград проверяется достижение пятого уровня, отмена и повторное выполнение квеста, бесплатное получение личного подарка и перезапуск.

При первом открытии существующего профиля в новой системе уровней текущий уровень становится отправной точкой: прежние XP и монеты сохраняются, выплаты начинаются со следующего нового уровня. Планы дней и купленные награды входят в резервную копию. У повторяющихся квестов дата задаёт начало серии; редактирование времени и дней недели применяется ко всей серии.
