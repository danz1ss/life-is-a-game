# Life is a Game

Текущая версия: **0.3.0**. Первая сырая MVP сохранена тегом `v0.1.0-mvp`.

Локальная RPG-система саморазвития для Windows. Квесты приносят опыт персонажу и связанным навыкам, дерево показывает общую карту развития, а золото можно обменивать на личные награды.

## Что уже работает

- главный квест и список задач на сегодня;
- режим дневного расписания с длительностью и временем начала;
- одноразовые и повторяющиеся квесты;
- три уровня сложности, XP, уровни и золото;
- единое интерактивное дерево с отдельными ветками;
- история, серии дней и график активности;
- личный магазин наград;
- редактирование профиля;
- импорт и экспорт резервной копии.
- отдельный планировщик без дубляжа сегодняшнего списка;
- разбор пропущенных одноразовых квестов без штрафов и автопереноса;
- архив завершённых и отменённых задач;
- одна активная долгосрочная цель с полем «Зачем» для каждого навыка;
- награда за достижение главной цели.

При первом запуске версии 0.2.0 данные MVP автоматически мигрируют: существующие квесты, навыки, XP, золото и история сохраняются.

## Приватность

В готовом приложении интерфейс загружается только из локальных файлов. Внешние HTTP(S) и WebSocket-запросы блокируются процессом Electron. Аккаунтов, телеметрии, аналитики и облачной синхронизации нет.

Данные хранятся в SQLite:

```text
%APPDATA%\life-is-a-game\life-is-a-game.sqlite
```

Резервную копию можно сохранить из раздела «Награды → Профиль и данные».

## Запуск

Готовый установщик находится в папке `release`:

```text
Life is a Game Setup 0.1.0.exe
```

Для разработки:

```powershell
npm install
npm run dev
```

Для проверки локальной production-сборки:

```powershell
npm run build
npm run desktop
```

Для создания нового установщика:

```powershell
npm run dist
```
